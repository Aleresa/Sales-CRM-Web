# Sales CRM · персональная веб-панель

Этот публичный репозиторий содержит **только интерфейс** CRM: HTML, CSS, JavaScript и иконку в папке `docs/`.

**Здесь нет клиентской базы, выгрузок, паролей или токенов.** Все коммерческие данные хранятся отдельно в приватном репозитории `Aleresa/Sales-CRM` и загружаются браузером через GitHub API после подтверждения доступа.

## Публикация на GitHub Pages (бесплатно)

В репозитории открой **Settings → Pages** и укажи:
- **Source:** Deploy from a branch
- **Branch:** `main`
- **Folder:** `/docs`
- Нажми **Save**.

После успешной публикации GitHub укажет адрес сайта; для этого репозитория ожидается `https://aleresa.github.io/Sales-CRM-Web/`.

## Вход и изменения

Сайт запрашивает GitHub fine-grained token, ограниченный **только** приватным репозиторием `Aleresa/Sales-CRM`.
- **Contents: Read-only** — просмотр аналитики.
- **Contents: Read and write** — редактирование клиентов и задач.

Токен не коммитится и не сохраняется в хранилище браузера; его нужно вводить при новом открытии страницы. Публичность сайта **не означает публичность данных**, однако исходный JavaScript виден всем.

**Не публикуй приватный репозиторий Sales-CRM** и не копируй оттуда папку `data` в этот репозиторий.

## Возможности

- Тёмная фиолетовая тема, цвет `#C7B3F0`;
- главная с текущим месяцем и графиком;
- объединение нескольких юридических лиц в одного реального клиента и групповые суммы продаж;
- клиенты, карточки и заметки;
- товарные категории и SKU с сортировкой;
- задачи, объединённые по реальному клиенту (исходные записи юрлиц сохранены);
- **«Вернуть продажи»**: анализ ранее покупавшихся SKU (янв–сен 2025 и 2026), список позиций для первого диалога, сохранение подборки, копирование текста и создание задачи.

Данные на исходном срезе — по 22 октября 2026. Дальнейшее обновление требует импорта в приватный репозиторий.

## Методика «Вернуть продажи»

Персональные подборки находятся в приватном `data/recovery-picks.b64` и загружаются только авторизованным GitHub-токеном. Этот файл содержит **сжатый список выявленных товарных потерь по каждому контрагенту**: максимум 9 SKU с крупнейшим снижением и 3 активные позиции. Отбираются **реальные отгрузки** из шести исходных XLS за одинаковые месяцы январь–сентябрь 2025 и 2026, возвраты не распределяются по клиентам.

Это shortlist, а не полная SKU-аналитика. При объединении нескольких юрлиц сумма по отдельному SKU в подборке может быть неполной, поскольку не все SKU каждого юрлица вошли в топ. Общие отгрузки на карточке клиента — полные. `data/crm-state.json` хранит `recoveryLists`, чтобы выбранные позиции сохранялись между входами. Подборки **не подтверждают текущие остатки, цены или прибыль**, и историческое падение не является гарантией будущей выручки.
